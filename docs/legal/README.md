## Cómo usar esta carpeta

- Un archivo por tema, numerado (`02-…`, `03-…`).
- Cada punto indica su **fuente**. Si no hay una fuente oficial, se marca **por confirmar**.
- Cuando algo se valida con el abogado, se anota la fecha y quién lo confirmó.
- Los documentos finales para el público (política de privacidad, aviso de cookies) se redactan a partir de
  estas notas, no se escriben aquí directamente.
